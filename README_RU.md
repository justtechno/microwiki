# Microwiki

## Языки

русский(текущий) | [english](README.md)

### О microwiki

Локальная вики-система / база знаний и Markdown-редактор с TUI (текстовым интерфейсом пользователя), созданные на Textual и Python.

Поддерживаемые системы:
- Linux-системы (например, Arch, Fedora, Debian, Omarchy, CachyOS, RHEL и т. д., даже Android через Termux или ChromeOS через Crostini)
- Windows
- MacOS

### Возможности (Features)

- Низкие системные требования
- Не требует графического окружения (это TUI, поэтому работает прямо в терминале)
- Поддержка внешних редакторов
- Частичная поддержка Vim-подобной раскладки (для ссылок в тексте всё еще нужна мышь, но всё остальное можно делать только с клавиатуры)

### Чего пока нет (Disfeatures)

- На данный момент поддерживается не так много функций
- Нет поддержки изображений
- Нет древовидной структуры заметок (как в Obsidian)

### Для кого это сделано

- Пользователи тайлинговых оконных менеджеров (Tiling WM)
- Разработчики
- Пользователи Vim / Nvim

### Установка
Существует три способа установки

##### Из исходного кода
Рекомендуемый способ — сборка из исходников

На Mac/Linux:
```bash
git clone # клонирование репозитория
cd ./microwiki # переход в клонированный репозиторий
make build # сборка проекта
```

На Windows:
```powershell
git clone # клонирование репозитория
cd ./microwiki # переход в клонированный репозиторий
make build_windows # сборка проекта с синтаксисом путей Windows
```

#### Запуск без сборки
Вы можете запустить microwiki без предварительной сборки. Сначала нужно клонировать репозиторий (как в шаге с установкой), а затем просто выполнить:
```bash
make run
```

#### Из релизов (Releases)
Просто перейдите в раздел релизов, выберите сборку для вашей системы (сборки под Mac нет, сорян), установите и запустите.
