# KEYBINDS CHEATSHEET
This file is a smal cheatsheet with all main keybinds

# General
HJKL - movement
ctrl+HJKL - force movement(if widget not allows to unfocus via HJKL)
enter - press button
m - back

# Wiki list screen
Ctrl+a - create wiki
Ctrl+d - delete wiki

# Wiki creation screen
Ctrl+HKJL - movement
Ctrl+Escape - Cancel wiki creation(move back to list)
Ctrl+Enter - Create wiki

# Built-in file manager
Arrows - movement
Ctrl+a - create file
Ctrl+d - delete file
Enter - Open file or press the button
Ctrl+r - rename file
m - back

# Wiki screen
Alt+e - toggle editor
Ctrl+s - save changes
Ctrl+f - open file manager
Tab - focus/unfocus editor
